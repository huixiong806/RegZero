## 1. 三十秒速览

- **项目**：RegZero（零号寄存器）（远端：GitHub `huixiong806/NeoMagicCompiler`，MIT License）
- **当前分支**：`main`
- **已拍板的核心架构与玩法决策**：
  1. **真实计算机术语**：采用准确、可迁移的真实计算机术语 + 视觉隐喻，专注打磨硬核且平滑的教学玩法闭环。
  2. **前端栈与双部署**：已彻底清理废弃的 `app/src-tauri` 与 `compiler-content/`，全面切换至 **`Vite + TypeScript + React + Tailwind CSS + CodeMirror 6`**，同时支持**线上静态部署**与 **`regzero-bridge` 本地一体托管**。
  3. **强游戏化交互 = 4 套数据驱动沙盘**（经 `SandboxRegistry` 扩展）：
     - `manual-cpu`（第 1 章：手动当 CPU + 语义操作记录 + 同色指令语法骨架 + `pcTrack` 分支循环轨道）
     - `memory-canvas`（第 2~3 章：2D 内存/指针/结构体/数据结构画布 + 预测挑战 + C↔汇编三联高亮）
     - `lexer-ast-lab`（第 4~5 章前端：切词传送带 + AST 积木台）
     - `pipeline-stage`（第 4~7 章后端：通电流水线 + `DrawVM` 画布 / RISC-V 监视器）
  4. **三类关卡节点 + DAG 技能树**：关卡分为 **`lesson`（概念关）**、**`practice`（零新知识主线巩固关）** 与 **`challenge`（不阻塞主线的硬核思维支线关，支持 `parInstructions` 最优指令挑战）**，由 `prerequisites` DAG 驱动解锁并配「自由探索」开关。
  5. **七章渐进拆分**：
     - 第 1 章：RISC-V 汇编入门（痛点驱动：算术 → 分支/循环 → 内存/数组 → 调试 → 函数/栈 → MMIO）
     - 第 2 章：C 语言核心基础
     - 第 3 章：数据结构与基础算法（动态数组、栈/队列、链表、树、哈希表/符号表、状态机）
     - 第 4 章：迷你编译器——绘图脚本 → `DrawVM`（本地 C 工程起步）
     - 第 5 章：核心编译器——C 核心子集 → RISC-V
     - 第 6 章：编译器功能扩展（数组/指针/字符串/`struct`/位运算等）
     - 第 7 章：编译优化与高阶算法（CFG、活跃变量、图着色寄存器分配、支配树与 SSA，可作终局主线或专题支线树）
  6. **代码质量铁律**：详见 [`代码质量规范.md`](代码质量规范.md)（严格单向分层、零关卡 ID 硬编码、TS `strict` 禁 `any`、纯函数状态机单测 + 全量 Rust/Web 门禁）。
