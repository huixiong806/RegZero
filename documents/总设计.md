# 总设计（核心规格与六章关卡大纲）

> 本文定义游戏的核心技术规格（RV32IM 模拟器、C 语言规格、第 3 章 `DrawVM` 栈式绘图机规格）、六章完整关卡大纲与 Judge 判定体系。
> 产品理念与强游戏化沙盘见 [`目标与形态.md`](目标与形态.md)，技术实现见 [`架构.md`](架构.md)。

## 1. 目标机器规格：RV32IM 模拟器

底层硬件模拟器复用现有的 `crates/riscv-simulator`，采用标准 **RV32IM** 32 位定长指令集、小端序、指令与数据同址。

### 1.1 指令集与伪指令

| 类别 | 指令 |
|------|------|
| R 型算术逻辑 | `add` `sub` `sll` `slt` `sltu` `xor` `srl` `sra` `or` `and` |
| R 型乘除 | `mul` `div` `divu` `rem` `remu` |
| I 型算术逻辑 | `addi` `slti` `sltiu` `xori` `ori` `andi` `slli` `srli` `srai` |
| 访存 | `lb` `lh` `lw` `lbu` `lhu` / `sb` `sh` `sw` |
| 分支与跳转 | `beq` `bne` `blt` `bge` `bltu` `bgeu` / `jal` `jalr` `lui` `auipc` |
| 系统与扩展 | `fence` `ebreak` `ecall` `slp`（周期等待指令） |

汇编器支持的常用伪指令（按关卡白名单逐步开放）：
`li` `la` `mv` `not` `neg` `nop` `j` `jr` `ret` `call` `beqz` `bnez` `blez` `bgez` `bltz` `bgtz` `bgt` `ble` `bgtu` `bleu` `seqz` `snez`。

### 1.2 寄存器与调用约定

32 个 32 位通用寄存器（`x0`–`x31`），`x0` 恒为 0。支持数字名与标准 ABI 别名：

| 寄存器 | ABI 别名 | 约定用途 |
|--------|---------|---------|
| `x0` | `zero` | 恒为 0 |
| `x1` | `ra` | 返回地址 |
| `x2` | `sp` | 栈指针（默认初值 `0x0000_F000`，向下增长） |
| `x3` | `gp` | 全局/静态数据基址 |
| `x5`–`x7`, `x28`–`x31` | `t0`–`t6` | 临时寄存器（调用者保存） |
| `x8`–`x9`, `x18`–`x27` | `s0/fp`–`s11` | 保存寄存器（被调者保存；`s0` 兼作帧指针） |
| `x10`–`x17` | `a0`–`a7` | 函数参数（前 6 个 `a0`–`a5` 用于 C 子集调用约定）、返回值（`a0`）、系统调用号（`a7`） |

### 1.3 内存布局与 MMIO

| 地址区间 | 用途 |
|---------|------|
| `0x0000_0000`–`0x0000_FFFF` | 64 KiB RAM（稀疏实现，未写入读回 0） |
| `0x0000_0800` | 函数模式运行时的引导桩位置（避开常用数据区） |
| `0x0000_4000` | `starlang` 编译产物的默认数据段起点（`DATA_BASE`） |
| `0x0000_F000` | 默认栈顶（`STACK_TOP`，向下增长） |
| `0xF000_0000` | **输出端口（只写）**：写入低 8 位输出一个字符 |
| `0xF000_0004` | **输入端口（只读 FIFO）**：每次读取消费 1 个字符，队列空返回 0 |
| `0xF000_0008` | **周期计数器（只读）**：返回当前已消耗周期数 |

### 1.4 系统调用（`ecall`，调用号在 `a7` / `x17`）

| `a7` | 语义 | 说明 |
|------|------|------|
| `0` / `5` | 退出程序 | 退出码取 `a0`，唯一会触发 `PauseReason::Exit` 的系统调用 |
| `1` | 输出字符 | 将 `a0` 低 8 位写入输出端口 |
| `2` | 输出整数 | 以十进制文本输出有符号整数 `a0` |
| `3` | 读取字符 | 从输入端口读 1 字节到 `a0`（空则 0） |
| `4` | 读取整数 | 跳过空白读取一个十进制整数到 `a0` |
| `99` | 查询周期 | 当前已消耗周期数写入 `a0` |

## 2. C 语言范围分层（第 2 章 vs 第 4 章 vs 第 5 章）

**核心原则**：第 2 章玩家学习的 C 语言知识用于**开发第 3~6 章的编译器**，因此其范围**大于**第 4 章的编译器源语言；编译器源语言按第 4 章（纯核心）与第 5 章（功能扩展）两阶段逐步覆盖。

| 类别 | 第 2 章学习范围（网页 `starlang` + 工程前置） | 第 4 章编译器源语言（纯核心） | 第 5 章编译器扩展 |
|------|-----------------------------------------|--------------------------|----------------|
| 类型 | `int`、`char`、`void`、一级指针、一维数组、`struct` | 仅 `int`（32 位有符号整数） | 补齐 `char`、一维数组、一级指针、`struct`、`void` |
| 运算符 | 算术、比较、逻辑、位运算、复合赋值、`++ --`、`?:`、`& *`、`. ->`、`sizeof` | `+ - * / %`、`== != < <= > >=`、`&& \|\| !`、单目 `-`、`=` | 补齐位运算、复合赋值、`++ --`、`& *`、`[]`、`. ->` |
| 控制流 | `if/else`、`while`、`do-while`、`for`、`break`、`continue`、`return` | `if/else`、`while`、`return` | 补齐 `for`、`break`、`continue` |
| 函数与作用域 | 局部变量、全局变量、多参函数（≤6）、递归 | 局部/全局变量、函数定义与递归调用（≤6 参数） | 字符串字面量、内建 I/O 运行时（`putchar`/`print_int` 等）、可选多文件 |
| 数据结构思维 | 字符串扫描、动态数组、链表/树、符号表查表（为写编译器铺路） | 玩家在本地标准 C 中自由使用标准库（`stdio`/`stdlib`/`string`） | 持续演进同一份本地 C 工程 |

## 3. 第 3 章目标机器规格：极简栈式绘图机（`DrawVM`）

为了让玩家在进入 RISC-V 寄存器与栈帧之前，轻松走通一次完整的「词法 → 语法树 → 代码生成」闭环并获得直观的视觉反馈，第 3 章采用一台只有 **15 条指令的极简栈式绘图机（`DrawVM`）**。

### 3.1 `DrawVM` 指令集

机器内部只有：**1 个操作数栈**、**编号变量槽（`0..63`）**、以及 **1 支虚拟画笔（位置 `x, y`、朝向角 `deg`、落笔/抬笔、颜色）**。

| 类别 | 指令 | 语义 |
|------|------|------|
| 栈与算术 | `PUSH <n>` | 将整数 `n` 压入栈顶 |
| 栈与算术 | `ADD` / `SUB` / `MUL` / `DIV` | 弹出栈顶两数 `b, a`，计算 `a op b` 压回栈顶 |
| 比较 | `LT` / `EQ` | 弹出 `b, a`，若 `a < b`（或 `a == b`）压入 `1`，否则压入 `0` |
| 变量槽 | `LOAD <slot>` / `STORE <slot>` | 读取槽位压栈 / 弹出栈顶存入槽位 |
| 控制流 | `JMP <label>` / `JZ <label>` | 无条件跳转 / 弹出栈顶若为 `0` 则跳转 |
| 绘图外设 | `MOVE` | 弹出栈顶距离 `d`，画笔沿当前朝向前进 `d` 像素（落笔状态则绘线） |
| 绘图外设 | `TURN` | 弹出栈顶角度 `a`，画笔顺时针旋转 `a` 度 |
| 绘图外设 | `PEN` | 弹出栈顶 `0/1` 控制抬笔/落笔 |
| 绘图外设 | `COLOR` | 弹出栈顶颜色编号切换画笔颜色 |

### 3.2 第 3 章源语言示例（绘图脚本）

```text
// 画一个逐渐放大的螺旋图案
let step = 10;
let i = 0;
pen(1);
while (i < 20) {
    move(step + i * 5);
    turn(90);
    i = i + 1;
}
```

**教学衔接价值**：玩家在第 3 章已经用真实 C 语言完整实现过「词法切分 → 表达式优先级与 AST → 变量槽分配 → `while`/`if` 标签跳转 → 栈式代码生成」，进入第 4 章只需把输出指令从 `DrawVM` 换成 `RV32IM` 并补上函数栈帧，学习曲线极其平滑。

## 4. 六章详细关卡大纲

### 4.1 第一章：RISC-V 汇编入门（15 关，纯网页 WASM / 可选本地单文件）

> 全章依托**沙盘 1「手动当 CPU」**（先手玩、自动录制指令、再写代码），复用现有 15 关测例与参考解。

| 关卡 | 核心新概念 | 强交互玩法重点 | 玩家任务 |
|------|-----------|--------------|---------|
| 1-1 | 寄存器与 `add` | 拖拽两数进 ALU 合成并录制 `add` | 计算 `x1 + x2` 存入 `x3` |
| 1-2 | 立即数 `addi` | 拖入常量卡片进入 ALU | 计算 `x1 + 7` 存入 `x2` |
| 1-3 | `sub` 与数值交换 | 用临时寄存器槽手动交换两数 | 计算 `x1 - x2` 并交换两数 |
| 1-4 | `mul` / `div` / `rem` | 除法拆解商与余数示意 | 拆分整数为商与余数 |
| 1-5 | 内存与 `lw` / `sw` | 在内存储物柜与寄存器间拖拽搬运 | 写入 `0x1000` 再读回 `x5` |
| 1-6 | `li` 与连续内存 | 按 `+4` 字节步进填充连续内存格 | 向连续地址写入 `1, 2, 3` |
| 1-7 | 条件分支 `beq` / `bne` | 手动拨动 PC 指针走不同分支轨道 | 两数相等置 1，否则置 0 |
| 1-8 | 大小比较 `blt` / `bge` | 数轴比较器交互 | 求两数较大值 |
| 1-9 | 标签与无条件跳转 `j` | 绕过危险指令块的路径选择 | 正确跳转避开陷阱指令 |
| 1-10 | 循环结构 | 观察循环计数器回跳与终止条件 | 求 `1 + 2 + ... + n` |
| 1-11 | 循环遍历数组 | 指针每步 `+4` 扫描内存阵列 | 求 `0x1000` 处数组前 `n` 项和 |
| 1-12 | 断点与倒退调试 | 亲手用时间轴倒退定位 Bug 帧 | 用调试器定位并修复循环错误 |
| 1-13 | 子程序 `jal` / `jalr` | 看到 `ra` 记下返回地址并跳回 | 编写并调用“平方”子程序 |
| 1-14 | 栈指针 `sp` 与嵌套调用 | 亲手把 `ra` 像积木一样压栈/弹栈 | 保存/恢复 `ra`，实现两层调用 |
| 1-15 | **章末综合：MMIO 流处理** | 输入队列 → CPU → 输出终端全景联调 | 读取输入序列累加并按阈值输出 |

## 5. Judge 判定体系

所有判定逻辑收口在 `crates/regzero-core`，WASM 与 `regzero-bridge` 共用同一套判定核心：

| 判定类型 | 适用章节 | 判定逻辑 |
|---------|---------|---------|
| `static` | 第 1~2 章 | 逐测例比对期望寄存器、内存、返回值、输出流与退出码 |
| `output` | 第 3~5 章前端关 | 按行规范化比对标准输出（忽略多余空行与首尾空白） |
| `draw_sim` | 第 3 章绘图关 | 用内置 `DrawVM` 执行玩家输出的指令流，比对生成的线段/像素轨迹集合与画布终态 |
| `compile_and_run` | 第 4~5 章代码生成关 | 把玩家编译器输出的 RISC-V 汇编交给 `riscv-assembler` + `riscv-simulator` 真机运行，校验返回值/输出/内存 |
| `scripted` | 随机化压力测试关 | Rust 内置随机生成测例并对比参考实现（如 `sort_check`、`expr_check`） |
