# 存档与草稿格式（网页端 + 本地桥接同步）

> 本文描述 网页版与本地桥接的持久化契约。
> 原则不变：**「通关进度存档」与「未提交的在线代码草稿」分离**，并在此基础上增加**网页端导出/导入备份**与 **`regzero-bridge` 本地双向同步**。

## 1. 两种持久化形态与职责分工

| 数据 | 存储位置 | 写入频率 | 作用 | 
| ----- | ----- | ----- | ----- | 
| **全局通关存档** | 浏览器 `localStorage`（`regzero.progress.v1`）+ 连接 `regzero-bridge` 时同步至本地 `user_progress.json` | 仅在提交判定或修改设置时 | 记录通关状态、最佳成绩、已解锁技能徽章与偏好设置 | 
| **在线编辑器草稿** | 浏览器 `localStorage`（`nmc:draft:{levelId}`） | 停止打字后 500ms 防抖 | 仅用于第 1\~2 章及在线沙盒未提交代码；本地项目模式的代码直接由玩家本地文件系统保存 | 
| **本地项目连接记录** | 浏览器 `localStorage`（`regzero.bridge.recent`） | 切换本地项目时 | 记住最近连接的 `regzero-bridge` 地址、项目名与 Watch 开关状态 | 

## 2. 全局存档格式（`version = 2`）

相比旧 Tauri 版（`version = 1`），`v2` 新增了技能图鉴进度、自由探索模式开关与本地项目元信息字段（所有新增字段均带默认值，向下兼容 `v1` 存档导入）：

```
{
  "version": 2,
  "lastModified": "2026-11-21T00:00:00Z",
  "levels": {
    "1-1": {
      "levelId": "1-1",
      "passed": true,
      "completedAt": "2026-11-21T00:00:00Z",
      "attempts": 2,
      "bestScore": 100,
      "bestInstructions": 4
    }
  },
  "unlockedConcepts": ["register", "add", "addi"],
  "settings": {
    "showHints": true,
    "freeExploreMode": false,
    "bridgeUrl": "http://127.0.0.1:17320",
    "autoWatchBuild": true
  }
}

```

### 字段说明

| 字段 | 类型 | 默认值 | 说明 | 
| ----- | ----- | ----- | ----- | 
| `version` | number | `2` | 存档格式版本；读取 `v1` 时自动迁移补齐默认字段 | 
| `lastModified` | string | UTC ISO 8601 | 每次保存刷新（用于网页与本地文件同步时比对新旧） | 
| `levels.<id>.passed` | bool | `false` | 一旦通过永不回退为 `false` | 
| `levels.<id>.completedAt` | string? | 省略 | 首次通关时间 | 
| `levels.<id>.attempts` | number | `0` | 累计提交次数 | 
| `levels.<id>.bestScore` | number? | 省略 | 历史最高分 | 
| `levels.<id>.bestInstructions` | number? | 省略 | 历史最少执行指令数（供结算页参考，不强制优化） | 
| `unlockedConcepts` | string\[\] | `[]` | 已点亮的知识点/图鉴节点 ID | 
| `settings.showHints` | bool | `true` | 是否显示行内提示 | 
| `settings.freeExploreMode` | bool | `false` | 自由探索开关：开启后允许跳过前置直接进入任意关卡（适合有基础玩家） | 
| `settings.bridgeUrl` | string | `http://127.0.0.1:17320` | 本地桥接服务地址 | 
| `settings.autoWatchBuild` | bool | `true` | 本地项目模式下，检测到文件保存是否自动构建并运行当前关测试 | 

## 3. 浏览器存档与 `regzero-bridge` 本地同步规则

纯网页游玩时，数据存放在浏览器 `localStorage` 中，容易受清缓存或换浏览器影响，因此提供两层保障：

1. **手动导出 / 导入（纯网页可用）**：

   * 设置面板提供「导出存档 JSON」与「导入存档 JSON」按钮，支持导入旧版 `v1` 存档。

2. **连接 `regzero-bridge` 时的自动合并同步**：

   * `regzero-bridge` 在本地用户配置目录（如 `~/.regzero/user_progress.json`）维护持久化文件；

   * 网页连上 `regzero-bridge` 时，执行**无损并集合并**而非粗暴覆盖：

     * 同一关卡 `passed` 取逻辑或（`a || b`），`attempts` 取较大值，`bestScore` 取较大值，`bestInstructions` 取较小正值；

     * `unlockedConcepts` 取并集；

     * `settings` 以 `lastModified` 较新的一方为准。

   * 若本地 `user_progress.json` 解析损坏，沿用现有保护机制：自动备份为 `user_progress.json.bak` 并重建合法文件。

## 4. 在线编辑器草稿格式

* Key：`nmc:draft:{levelId}`（例如 `nmc:draft:1-1`；独立沙盒使用 `nmc:draft:sandbox-asm` / `nmc:draft:sandbox-c`）。

* Value：

```
{
  "level": "1-1",
  "code": "add x3, x1, x2\necall\n",
  "savedAt": "2026-11-21T00:05:00Z"
}

```

* 读取失败或字段不合法时自动清理该 Key 并回退到关卡初始代码。

* 切换到「本地项目模式」时，草稿系统停用，所有代码编辑以玩家本地磁盘文件为唯一真源。
