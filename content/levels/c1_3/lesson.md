想计算两个寄存器的差，使用 **`sub`**（顺序敏感：`目标 = 左 - 右`）：

```asm
sub  目标, 左, 右      # 目标 = 左 - 右
addi 目标, 源, 0       # 加上 0 即可把源寄存器的值复制一份到目标
```

> 便捷简写：因为「加 0 复制」用得极多，汇编器提供了简写 **`mv 目标, 源`**，它会被直接翻译成 `addi 目标, 源, 0`，在硬件里走的是完全相同的加法通路。

向寄存器写入新值会**直接覆盖**原来的数据。想交换 `t0` 和 `t1`，必须先借空闲的 `t3` 把旧值暂存起来。

**本关任务**：先计算 `t2 = t0 - t1`，再把 `t0` 和 `t1` 里的数值互换。
