# 像素调色盘

## 1. 三把按位手术刀

这组指令把两个 32 位数的**第 0~31 位各自独立运算**，彼此不进位：

| 指令（寄存器 / 立即数） | 逐位规则 |
| --- | --- |
| `and` / `andi` | 同为 `1` 才得 `1` |
| `or` / `ori` | 只要有 `1` 就得 `1` |
| `xor` / `xori` | 不同得 `1`，相同得 `0` |

## 2. 装载大常数：`li` 与 `lui`

`addi` 只能装下 12 位有符号立即数（`-2048 ~ 2047`）。装入更大的常数可使用伪指令 `li rd, 常数`，汇编器会自动展开为高位 `lui` + 低位 `addi`。

## 本关任务

`t0` 存着打包颜色 `0x00RRGGBB`（最高 8 位可能含非零杂讯，结果 `t4` 的最高 8 位须为 `00`）：
1. 拆出三个 8 位通道：`t1 = R`、`t2 = G`、`t3 = B`；
2. 将红蓝互换重新打包为 `0x00BBGGRR`，存入 `t4`。
