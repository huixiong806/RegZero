# 呼叫系统

恭喜来到第 1 章最后一关！以前每关底部自动隐藏的那条 **`ecall`** 指令，现在彻底交到你的手里。

## 1. 什么是系统调用（`ecall`）？

程序无法独自完成「把整数格式化成十进制打印」或「通知系统我已经算完退出」等高级服务。执行 **`ecall`** 时，CPU 会暂停用户代码、把控制权交给操作系统/模拟器，由 **`a7`** 寄存器指定要调用的服务：

| `a7` 编号 | 功能 | 参数与返回值 |
| --- | --- | --- |
| `0` | 结束程序（`SYS_EXIT`） | `a0` = 退出码（通常 `0`） |
| `1` | 输出 1 个 ASCII 字符（`SYS_PUTC`） | `a0` = 字符编码（空格为 `32`） |
| `2` | 输出十进制有符号整数（`SYS_PUTINT`） | `a0` = 要打印的整数 |
| `3` | 读入 1 个字符（`SYS_GETC`） | 返回字符在 `a0` |
| `4` | 读入十进制有符号整数（`SYS_GETINT`） | 返回整数在 `a0` |

## 2. 本关毕业任务

- 输入：第 1 个数是正整数 `n`（`n >= 1`），随后是 `n` 个有符号整数（可能全为负数！）。
- 输出：先打印这 `n` 个数的**总和**，再打印一个**空格**（`32`），再打印它们的**最大值**，最后调用 `a7 = 0`、`a0 = 0` 的 `ecall` 正常退出！
