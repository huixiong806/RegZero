# 岔路口

## 1. 为什么要学会「跳转」？

前 5 关的代码无论输入什么数字，都是从第 1 行到最后一行**一条直线顺序跑完**。但现在我们要实现**「比较 `t0` 和 `t1`，把较大的那个存入 `t2`」**——这就需要 CPU 根据大小关系**跳过**不需要执行的那一段代码。

## 2. 本关新指令：跳转

```asm
blt a, b, 目标   # 如果 a < b，跳到目标处（Branch Less Than）
bge a, b, 目标   # 如果 a >= b，跳到目标处（Branch Greater or Equal）
j   目标         # 无条件直接跳到目标处（Jump）
```

## 3. 跳到哪里？用「标签（路标）」标记位置

跳转指令里的「目标」需要在代码中用**标签（Label）**标出——写法是在对应位置单独写一行 `名字:`（英文加冒号，例如 `use_t1:`）：

- 标签**不是指令**，也不会消耗执行步数，只是贴在代码上的**路标 / 书签**；
- 名字完全由你自由取名（这里 `use_t1` 意为「改用 `t1`」）；
- 当跳转发生时，CPU 内部的**光标 PC（程序计数器）**会直接飞到对应路标处继续往下执行。
